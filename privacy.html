Privacy Policy

App: ai in my opinion Pinterest connector
Last updated: October 16, 2026

What this app is

This is a personal tool that connects the owner's own Pinterest business account ("ai in my opinion") to AI assistants such as Claude, so the owner can create pins, manage boards and read their own analytics. It is not offered to the public.

What data it uses

When the account owner signs in with Pinterest, the app receives an access token and can read and write that account's own boards, pins and basic account information and analytics, only within the permissions the owner approves. It does not access other people's Pinterest accounts.

How data is stored

Access tokens are stored encrypted and are used only to make requests to the Pinterest API on the owner's behalf. Pin and board data is not stored by the app beyond what is needed to complete a request.

Sharing

Data is never sold, rented or shared with third parties for advertising. Data is only sent to Pinterest (to carry out the requested action) and to the AI assistant the owner is using.

Removing access

Access can be revoked at any time in Pinterest settings under Security and apps / connected apps. Revoking access stops the app from using the account.

Contact

Questions about this policy can be submitted through this project's GitHub issues page.
